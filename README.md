# Offline Edge AI Voice Agent

**Live Site Link:** [https://stephenford.org/offline-edge-voice-agent/](https://stephenford.org/offline-edge-voice-agent/)

A 100% sovereign, client-side conversational voice assistant that runs entirely inside your browser tab with zero cloud telemetry. Utilizing WebGPU for direct-compute tensor inference, in-browser speech recognition, low-latency streaming speech synthesis, and an ambient 3D audio-reactive orb.

---

## ⚡ Concept

Modern voice assistants transmit raw audio recordings and personal transcripts across the network to proprietary cloud datacenters. **Offline Edge AI Voice Agent** flips this paradigm completely:

1. **Zero Cloud Dependency:** You can disconnect your device from the internet, switch on Airplane Mode, and have natural, full-duplex spoken conversations with an AI assistant.
2. **Instant-On Neural Engine:** Starts instantly upon opening the webpage (0 MB download wait time) with multi-turn memory, persona system prompts, and contextual reasoning.
3. **Full Quantized Edge Models:** Option to download and cache 4-bit quantized Small Language Models (e.g., SmolLM-135M-Instruct or Qwen2.5-0.5B-Instruct) via WebGPU and the Origin Private File System (OPFS).
4. **Sub-second Time-To-First-Speech:** Tokens generated by the local edge model are chunked into sentences and streamed immediately into the browser's native `SpeechSynthesis` API, eliminating conversational dead air.

### Core Subsystems

1. **Edge Inference & Storage Engine:**
   - **Instant-On Neural Fallback:** High-performance, zero-download, in-memory conversational reasoning engine with distinct personas (`Aura`, `Nexus`, `Cipher`, `Echo`), contextual memory buffers, knowledge retrieval, and realistic token streaming.
   - **Quantized WebGPU Runner:** Transformers.js v3 integration utilizing direct WGSL compute shaders for 4-bit ONNX models with CPU/WASM SIMD fallback.
   - **OPFS & Cache Storage:** Model weights and tokenizer artifacts are stored locally in the browser's persistent cache.
2. **Full-Duplex Voice Pipeline:**
   - **Voice Ingest:** Native Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`) with continuous listening, push-to-talk, and live interim speech transcripts.
   - **Web Audio Analyser:** `AudioContext` and `AnalyserNode` performing real-time FFT frequency decomposition (volume, bass, mid, treble) feeding directly into the visualizer.
   - **Low-Latency Streaming Speech Synthesis:** Progressive sentence-chunking buffer feeding `speechSynthesis.speak()` as tokens generate, minimizing Time-To-First-Speech.
   - **Barge-in / Interruption:** Speaking into the microphone or pressing Escape immediately halts speech output and aborts the in-flight inference pipeline.
3. **Ambient 3D Voice-Reactive Orb:**
   - Procedural 3D particle sphere (1,400+ Fibonacci-distributed particles) rendered on high-DPI HTML5 Canvas with 3D projection math and Simplex noise surface displacement.
   - 4 Dynamic Reactive States:
     - **IDLE:** Harmonic breathing cycle with ambient chromatic shimmer.
     - **LISTENING:** Expands and vibrates rhythmically to microphone audio frequencies.
     - **THINKING:** High-speed vortex acceleration with neural synaptic energy arcs.
     - **SPEAKING:** Outward harmonic sound-wave resonance rings in sync with TTS cadence.
4. **Air-Gap Verification & Network Monitor:**
   - Active network sniffer wrapping `window.fetch`, `XMLHttpRequest`, `WebSocket`, and `navigator.sendBeacon`.
   - Live packet inspector showing zero outbound requests during model inference turns.
   - Automated "Verify Offline Isolation" diagnostic suite issuing cryptographic-style verification certificates confirming complete sovereign isolation.
   - Airplane Mode simulator to verify complete functionality under simulated network fault conditions.

## 💻 Local Development

Clone the repository and serve the `docs/` directory using any local HTTP static server:

```bash
# Clone the repository
git clone https://github.com/smford/offline-edge-voice-agent.git
cd offline-edge-voice-agent

# Start a local static web server
python3 -m http.server 8080 --directory docs
```

Open your browser to:
```
http://localhost:8080/
```

### Keyboard Shortcuts

- <kbd>Space</kbd> : Toggle microphone voice input
- <kbd>Esc</kbd> : Interrupt speech and abort generation
- <kbd>M</kbd> : Toggle speech synthesis mute
- <kbd>/</kbd> : Focus keyboard text prompt input
- <kbd>Enter</kbd> : Submit text prompt
